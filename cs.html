起源 / Origin

John Washam（GitHub: jwasham）是一个没有计算机科学学位的人。他花了 8 个月 全职自学，最终拿到了 Amazon 的软件工程师 offer。他将自己的学习计划开源在 GitHub 上，成为 GitHub 上最受欢迎的 CS 自学路线图之一。

他的核心方法论只有四个字：间隔重复（Spaced Repetition）。他制作了 1,792 张电子记忆卡，在超市排队、公交车上、任何碎片时间里反复复习。一张卡片回答正确还不够——需要在一段时间内多次正确，才会标记为「已掌握」。

「 You need to successfully recall the same information
multiple times over increasing intervals
to properly commit it to long-term memory. 」
— John Washam, Coding Interview University

间隔重复 / Spaced Repetition

看过不等于记住。 人的遗忘曲线是陡峭的——24 小时内遗忘 50%，一周后遗忘 70%。间隔重复是唯一被科学证明能对抗遗忘的学习方法。

核心原则：

  1. 制作记忆卡片——每张卡片只包含一个概念。正面是问题，背面是答案。自己制作卡片的过程本身就是一次学习。
  2. 每天复习——每天花 5-10 分钟翻看卡片。不需要大块时间，排队、等车、吃饭前都可以。
  3. 间隔递增——答对的卡片，下次复习间隔延长；答错的卡片，回到短间隔重新开始。典型的间隔：1天 → 3天 → 7天 → 14天 → 30天 → 90天
  4. 多次确认——不要一次答对就标记「已掌握」。需要多次在不同时间点正确回答，才算真正内化。
  5. 在上下文中学习——不只是背卡片，还要动手写代码。每学完一个主题，立刻做 2-3 道相关的编程题。
「 在学习这些内容的过程中不断做问题，
而不是之后。
你被雇佣的不是因为你的知识，
而是因为你知道如何应用这些知识。 」
— jwasham, Coding Interview University

学习计划 / Study Plan

Jwasham 的原始计划是一个 多个月的全职学习路线。如果你无法全职投入，可以将它拆解为更长的周期。以下是建议的学习节奏：

阶段一
算法复杂度 & 数据结构基础（2-3 周）
阶段二
排序、搜索、递归（2-3 周）
阶段三
树、图、动态规划（3-4 周）
阶段四
系统设计 & 操作系统（2-3 周）
阶段五
面向对象编程 & 设计模式（1-2 周）
阶段六
网络、数据库、安全（2-3 周）
阶段七
模拟面试 & 综合复习（2-4 周）

每天的学习流程：看视频/阅读 → 做笔记 → 制作记忆卡片 → 写代码实现 → 做编程题。每天结束时花 5 分钟翻看当天的卡片。

常见错误 / Common Mistakes

Jwasham 在回顾自己的学习历程时，总结了几个关键教训：

1. 你不可能记住所有东西。 看了数小时的视频和笔记，几个月后大部分都忘了。记忆卡片是唯一的解决方案。

2. 不要用别人的记忆卡片。 制作卡片的过程本身就是学习。别人的卡片包含太多你不需要的细枝末节。

3. 在学习过程中做编程题。 不要等到学完所有知识点才开始做题。每学完一个主题，立刻做 2-3 道相关的题目。

4. 专注。 学习过程中会有很多干扰。放点纯音乐，关掉手机通知，每天保持固定的学习时间。

「 我不是天才。
我只是花了比别人更多的时间
在正确的方法上。 」
— John Washam
